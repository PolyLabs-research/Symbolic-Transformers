# Grid embedding ablation, reduced CPU run (seed 1)

Generated by `python scripts/grid_experiment.py --out-dir runs/grid_small --n-train 2000 --epochs 8`.
Raw numbers: `grid_small_seed1.json` (one `evaluate_grid.py` report per arm).

**Setup.** tiny model (2 layers, d=128), identical data and seed for every arm, 8 epochs,
batch 32, lr 0.0003, all arms with tied output weights.
Indices for variables and predicates are drawn from 0-99
with 60-79 held out of training;
`test_holdout` uses only the held-out band, `test_far` only 100-199
(never in range). Train 32684 samples from 2000 formulas.

## Reading

1. **Unseen indices break the learned baseline and not the grid models.** On seen indices all three arms are
   identical (53.6% overall, 74% on structure targets). On the held-out band the learned baseline falls to
   25.8% overall and to 2.8% on structure targets that follow a numeral: after an index it never trained on it
   cannot continue the formula. `grid_linear` is unchanged (53.6 / 75.2) and `grid_conv` nearly so (53.4 / 74.1).
   The thermometer panel gives an unseen index an embedding between its neighbours, and that is enough.
2. **Extrapolation beyond the trained range favours the linear thermometer.** On 100-199, `grid_linear` keeps
   68.7% structure / 62.8% after-numeral; `grid_conv` drops to 51.7 / 24.9; learned stays broken (35.7 / 2.5).
   The conv encoder sees shape and has never seen panels this full; the linear projection of a cumulative code
   degrades gracefully.
3. **Nobody copies yet.** `copy` accuracy (predicting a bound variable's index when it is reused) is 1.5% on
   seen indices for every arm, i.e. chance over the 80-index pool, and 0% on unseen indices. After 8 epochs on
   2k formulas no arm has learned variable binding, so the tied-output claim ("an unseen index can be
   predicted from its panel") is untested here, not refuted. This needs the full run and probably a
   binding-focused dataset.
4. **The geometry is real.** For `grid_linear` the nearest neighbour of a numeral embedding is an adjacent index
   100% of the time (learned: 5%), Spearman(distance, |i-j|) 0.45 vs 0.11. `grid_conv` sits between.
5. **Panel noise is not free.** Flipping 1% of panel bits costs `grid_linear` 9 points overall and 5% costs 36.
   Training never saw noise; `--noise-flip` augmentation at training time is the obvious next lever.

## Caveats

- Single seed, 8 epochs, 2k formulas, CPU. The full driver run (10k formulas, 30 epochs, 3 seeds) is the
  version to quote.
- All arms used tied output weights. For the structure result an untied learned baseline is a fairer control
  (its unseen rows stay at their random init instead of being pushed away by the softmax); see the
  `learned_untied` arm when present in the table below.
