# Magnitude comparison, held-out band off-centre (350-449), seed 1

Generated by `python scripts/magnitude_experiment.py --out-dir runs/magnitude_offcenter --holdout 350-449 --seeds 1 --epochs 30`
plus `--arms sinusoid` and `--arms sinusoid_smooth`. Raw numbers: `magnitude_offcenter_seed1.json`.

Same task and budget as `magnitude_3seeds.md` (values 0-499, 20k training pairs, tiny model, 30 epochs) with
one change: the held-out band is 350-449 instead of 200-299, so an unknown token can no longer be answered
by treating it as "roughly average". Five arms, one seed each:

| arm | numeral embedding | what it tests |
|---|---|---|
| `learned_untied` | learned row per token | the original model |
| `grid_linear` | `Linear(625)` over the thermometer panel | nested code |
| `grid_conv` | conv over the 25×25 panel | nested code, read as a shape |
| `sinusoid` | `Linear(64)` over sin/cos of *k*, periods 2-1250 | ordinal code, no nesting |
| `sinusoid_smooth` | same, periods 32-1250 | smooth ordinal code, no nesting |

## Reading

1. **The centring artifact is gone and the grid result stands.** `learned_untied` drops from 86.7% (centred
   band) to 61.7% on held-out pairs, and from 95.5% to 63.2% when one operand is unseen. `grid_linear` is
   93.5% overall and 99.5% with one unseen operand; `grid_conv` 91.8% / 97.9%.

2. **Both operands unseen, gap over 20:** grid_linear 78.8%, grid_conv 71.7%, sinusoid 52.1%,
   sinusoid_smooth 57.1%, learned 54.2%. Only the panel arms are clearly above chance. Equal unseen pairs are
   100% for every fixed-feature arm (identical inputs) and 89% for the learned table.

3. **Magnitude readout on unseen values (Spearman):** grid_linear 1.000, grid_conv 0.975, sinusoid 0.770,
   sinusoid_smooth 0.294, learned 0.180. A linear readout of *k* fitted on trained numerals transfers to the
   gap only for the panel arms.

4. **So it is nesting, not smoothness.** Both sinusoid codes are smooth in *k* (the smooth one more so) and
   both interpolate poorly. The thermometer panel for an unseen *k* is a subset of panels the model trained
   on; the cells inside the gap only ever receive gradient together, from panels above the gap, so they are
   pushed as a block and the embedding walks monotonically through the gap. A Fourier basis has no such
   constraint: a linear map fitted on the two sides of a gap is free to do anything inside it, and it does.

5. **Beyond the trained range nothing works**, as before: panel cells above 499 never received gradient, and
   the sinusoid readouts invert (far Spearman −0.97 and −1.00). Extrapolation needs an encoder with shared
   structure across cell positions, not 625 independent columns.

6. **Precision inside the gap is still coarse** for the panel arms: gaps under about 20 are at chance.

Single seed; the three-seed run with the centred band (`magnitude_3seeds.md`) carries the error bars for the
panel and learned arms and for the default sinusoid.
